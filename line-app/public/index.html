นโยบายความเป็นส่วนตัว (Privacy Notice)

บริษัท อินโนว จำกัด (“Innow”) เก็บรวบรวมข้อมูลของคุณเพื่อจัดการสิทธิ์เข้าถึงสื่อการเรียนของ Workshop ที่คุณเข้าร่วม และติดต่อคุณเกี่ยวกับการเรียน

ข้อมูลที่เก็บ

  • LINE User ID ชื่อที่แสดง และรูปโปรไฟล์ LINE (ได้รับจาก LINE Login)
  • ชื่อจริง นามสกุลจริง และอีเมลที่คุณกรอก
  • รายการ Workshop ที่คุณได้รับสิทธิ์ และประวัติการรับสิทธิ์
  • สถานะการเป็นเพื่อน LINE Official Account ของ Innow

วัตถุประสงค์

  • ยืนยันตัวตนและให้สิทธิ์เข้าถึงสไลด์ Prompt และสื่อเสริมของ Workshop
  • ติดต่อเรื่องการเรียน เช่น แจ้งสื่อการเรียนใหม่ของ Workshop ที่คุณเข้าร่วม
  • ส่งข่าวสารและโปรโมชันเฉพาะเมื่อคุณให้ความยินยอมแยกไว้เท่านั้น

การเก็บรักษาและสิทธิ์ของคุณ

ข้อมูลจัดเก็บบนระบบคลาวด์ที่มีการควบคุมการเข้าถึง และไม่เปิดเผยแก่บุคคลภายนอกโดยไม่มีฐานทางกฎหมาย คุณมีสิทธิ์ขอเข้าถึง แก้ไข ลบ หรือถอนความยินยอมได้ตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 โดยติดต่อทีมงานผ่าน LINE Official Account ของ Innow
